# HOTEL-MANAGMENT-SYSTEM
Hostel Management System – Project Description

Developed a Hostel Management System using the C programming language and HTTP server architecture to manage hostel student records efficiently. The system provides a centralized platform for storing and managing student information, room allocation details, and contact records. It supports adding, viewing, searching, and deleting student records while maintaining persistent data storage through file handling. The application follows a client-server architecture and provides a web-based interface for hostel administration.

Key Features:

Student Registration and Record Management
Hostel Room Allocation Management
Add, View, Search, and Delete Student Records
Student Contact Information Management
File-Based Data Storage and Retrieval
Web-Based User Interface
Client-Server Architecture using HTTP Protocol
Real-Time Record Updates

Technologies Used:

Programming Language: C
Concepts: Socket Programming, HTTP Server, File Handling
Database: File-Based Storage (students.txt)
Tools: VS Code, Git, GitHub
